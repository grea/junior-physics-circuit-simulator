# 初中物理电路模拟器

这是一个面向初中物理教学的交互式电路模拟器，支持：

- 串联电路
- 并联电路
- 混合电路
- 电池、电阻、灯泡、开关
- 可拖拽元件摆放与导线连接
- 基于 MNA（Modified Nodal Analysis）方法求解电路
- 实时显示总电流、总电阻、总功率与亮度

## 运行方式

```bash
npm install
npm start
```

然后打开浏览器访问：

```text
http://localhost:3000
```

## 设计理念

- 可视化：使用 SVG 直接绘制实验板和电路连接，贴近真实实验教具。
- 交互式：学生可以直接拖拽元件并连接线路，理解串联与并联的差异。
- 学习导向：通过电流、电阻、功率和亮度等量化信息，帮助学生理解欧姆定律和电路规律。
- 教学扩展：适合课堂讲解、实验辅助和项目展示。

## 目录说明

- `index.html`：页面结构
- `styles.css`：界面样式
- `app.js`：交互逻辑与 MNA 求解
- `server.js`：静态服务器
